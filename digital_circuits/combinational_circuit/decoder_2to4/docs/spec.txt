DUT: decoder_2to4
INPUT: 
	en, [1:0] din
OUTPUT:
	reg [3:0] out
    
FUNCTION:
	out=en?1<<din:0;
 1<<0 = 0001
 1<<1= 0010
 1<<2=0100
 1<<3=1000


CASES:
1, Normal case:
	i, en=0, din= 01
	out=0?1<<01:0 = 0
	verified in gtkwave

	ii, en=1, din= 01
	out=1?1<<01:0 = 1<<1 = 0001<<1= 0010=0010
	verified in gtkwave

2, Boundary case
	i, en=0, din=00
	out=0?1<<0:0= 0000
	verified
	ii, en=1, din=11
	out=1?1<<3:0= 0001<<3= 1000
	verified

3, different control same input:
	i, en=0, din=10;
	out=0?1<<2:0=0
	verified
	ii, en=1, din=10;
	out=1?1<<2:0=0100
	verified

4, same control different input:
	i, en=1, din=10;
	out=1?1<<2:0;0100
	verified
	ii, en=1,din=01;
	out=1?1<<1:0=0010
	verified

5, output transistion:
	en=0->1, din=11->00
	out=0?1<<3:0=0
	out=1?1<<00:0= 0001
	verified.
